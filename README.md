# Conecta Novo Recreio
Sistema web desenvolvido para o Clube de Mães Novo Recreio.
## Objetivo
Modernizar a presença digital da instituição, facilitando a divulgação de projetos sociais, cursos gratuitos, atividades infantis e informações institucionais.
## Tecnologias
### Frontend
- HTML5
- CSS3
- JavaScript
### Backend
- Python
- FastAPI
- API REST
### Banco de dados
- A definir
## Estrutura
- frontend: interface pública e painel administrativo.
- backend: API e regras de negócio.
- database: estrutura e migrações do banco.
- docs: documentação técnica.
