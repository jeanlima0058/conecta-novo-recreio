# conecta-novo-recreio
Conecta Novo Recreio é um sistema web desenvolvido para o Clube de Mães Novo Recreio, com foco na divulgação de projetos sociais, cursos gratuitos e atividades infantis. Criado com HTML, CSS e JavaScript, busca ampliar a visibilidade da ONG, facilitar o acesso às informações e conectar a instituição a voluntários, parceiros e doadores.
